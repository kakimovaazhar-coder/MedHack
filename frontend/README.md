# MedRep frontend

Три панели: история с поиском, разговор, бланк по Word-шаблону. Основные действия —
микрофон, загрузка аудио, Word и отправка в тестовую МИС.

```sh
npm --prefix frontend ci
npm --prefix frontend run dev
```

На одном компьютере Vite обращается к backend на 127.0.0.1:8001.
Для другого сервера задайте VITE_API_URL в frontend/.env.local (адрес включает /api).
Обычный адрес открывает сохранённое серверное демо. Если записи нет или сервер
недоступен, отображается явно обозначенный встроенный учебный пример.
`?demo=1` сразу запускает учебный разговор без запросов к распознаванию и OpenAI.
`?mode=platform` открывает пустой приём. Переключатель «Демо / Приём» хранит черновики
отдельно в памяти вкладки. Демо можно поставить на паузу и повторить.

Сначала проверьте бланк и отметьте «Проверено». Word сохраняет предоставленный
командой шаблон. «Отправить в МИС» открывает короткое подтверждение тестовых данных,
после чего вызывает готовые backend-маршруты /form → /confirm → /mis-export.
Успех отображается только по квитанции тестовой МИС. «Прочитать из МИС» показывает
сохранённые разделы. При обрыве ответа повтор использует ту же подтверждённую
ревизию и не создаёт второй документ. Ключ МИС остаётся на backend.

Для записи язык определяется автоматически. Загрузки принимают WAV, MP3, M4A,
WebM, OGG, FLAC, AAC, MP4 до 30 МБ. Микрофону нужен localhost или HTTPS.
Качество настоящего WhisperX на сервере команды проверяется отдельно;
сохранённое демо позволяет показать весь путь без нового распознавания.

```sh
npm --prefix frontend run check
```

Docker и подготовка серверов описаны в корневом README. Backend, его контейнеры,
формат расшифровок и шаблон DOCX в этой frontend-адаптации сохранены.
