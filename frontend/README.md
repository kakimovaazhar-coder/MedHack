# Frontend — зона разработчика интерфейса

Планируемый стек: React + TypeScript (разрешён исходным заданием).
Приложение ещё не создано, чтобы команда могла независимо выбрать UI и сборку.
Корневой package.json — только инструменты контракта, не frontend-приложение.

Начните с [инструкции интеграции](../docs/frontend-handoff.md).
Общий клиент: `../contracts/client.ts`, сгенерированные типы: `../contracts/api.d.ts`.
Фикстуры: `../contracts/examples/`. Backend можно поднять через Docker Compose.

Пустые textarea преобразуйте из null в пустую строку при отображении и обратно в null
перед сохранением. Не держите собственную копию названий полей и статусов API.
Добавление frontend-сервиса в Compose — следующая задача после создания приложения.
