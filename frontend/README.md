# MedScribe — рабочее место врача

React + TypeScript. Три блока: прошлые записи и рекомендации, текущая расшифровка,
лист консультации по предоставленному Word-бланку. Язык определяется автоматически;
выбирать язык и формат приёма не требуется. Поля можно исправить перед выгрузкой.

## Быстрый просмотр

Требуется Node.js 22.12 или новее. Из корня репозитория:

```sh
npm --prefix frontend ci
npm --prefix frontend run dev
```

Открыть http://127.0.0.1:5173 и нажать «Пример приёма». Синтетический пример показывает
постепенное появление реплик и заполнение бланка без микрофона и внешнего AI.
Ручные правки врача сохраняют приоритет. Выгрузка Word создаёт `.docx` на основе
`public/templates/therapist.docx`; документ можно открыть и распечатать в Word.

Для существующего backend Vite проксирует `/api` на http://127.0.0.1:8000.
Другой сервер: скопировать `frontend/.env.example` в `frontend/.env.local`, указать
`VITE_API_URL` и перезапустить Vite. Не помещать серверные ключи во frontend.

## Совместимость с backend ветки medhub-demo

Исходные `backend/`, `speech_worker/` и `contracts/` сохранены без изменений.
История, загрузка аудиофайла и анализ используют существующий `/api/workspaces`.
Подробности настройки WhisperX и OpenAI — в [документации backend](../docs/demo-workspace.md).

Подробный бланк содержит 13 разделов, а текущий серверный контракт — шесть укрупнённых
полей. Frontend сопоставляет ответы с разделами и сохраняет подробный документ в
состоянии страницы. Долговременное хранение полного Word-бланка требует расширения
контракта backend. Обновление страницы не является сохранением документа.

Микрофонный адаптер предпочитает два дополнительных маршрута, если они подключены:

- `GET /api/live/capabilities` → `{ "enabled": true, "speech": "configured_unverified" }`;
- `POST /api/live/transcribe?language=auto` — сырое тело `audio/wav`, самостоятельный
  PCM WAV 16 kHz mono примерно за 6 секунд; ответ `{ "language": "ru", "segments":
[{ "id": "...", "start": 0, "end": 5, "speaker_id": null, "role": "unknown", "text": "..." }] }`.

Время сегментов в ответе относительно текущего фрагмента. Если live-маршруты
возвращают 404 или 405, адаптер использует готовый `/api/workspaces`: создаёт отдельную
временную сессию для WAV-фрагмента, загружает аудио с `language=auto`, затем опрашивает
задание. После успеха или окончательной ошибки сессия удаляется. Незавершённое задание
сохраняется для повторной попытки; оставленные сессии очищаются по TTL backend.
Сетевые ошибки не заменяются демотекстом. Идентификаторы реплик соответствуют UUID
контракту сервера. Проверка с реальным speech backend не проводилась: фактическая
скорость и качество распознавания зависят от настроенного сервера команды.

## Docker

Опциональный overlay добавляет frontend, не меняя основной compose backend:

```sh
docker compose -f compose.yaml -f compose.frontend.yaml up --build
```

Интерфейс: http://127.0.0.1:8080. Настройки существующего backend берутся из корневого
`.env` согласно его документации.

## Проверки

```sh
npm --prefix frontend test
npm --prefix frontend run build
npm --prefix frontend run format:check
```

Клинические сведения не записываются в localStorage. Учебный пример отмечен в
интерфейсе; внесение собственного материала очищает учебные данные.
